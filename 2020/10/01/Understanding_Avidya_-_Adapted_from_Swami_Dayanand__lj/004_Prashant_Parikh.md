Dave ji,  
  
Frankly it is best not to get into semantics if the general picture is well understood. If one has to explain cause and effect relationships, one cannot help but invoke Karana Brahman, as Ishvara. Indeed, the svarupa of Brahman is beyond this kind of relationship, but the tAtparyam has to be understood. Avidya has no basis whatsoever when one speaks of Akshara Brahman. Since Avidya is being discussed here, we have to introduce Maya, Ishvara, cause-effect, so on and so forth. The context matters.  
  
If one takes a text such as Drk-drsya viveka, one may, using this criteria, even fault the author for assuming that there is a knower and a known, when even such categories are rendered non-existent. Likewise for the Gita, if one goes only by some citations impelling Arjuna to do his duty as a kshatriya. The vision of the whole cannot be unfolded at all times in all places. It is assumed that in a learned group like this, folks have the basic context already established. And we can give the benefit of the doubt to Acharyas accordingly, or at the very least humbly inquire into what is meant if in doubt.  
  
Thank you,  
Prashant
