Namaskar:

Shraddha is an integral part for all believers. Just like Dharma, it is impossible to describe Shraddha by a single English word. We can safely say that Shraddha includes the combination of faith, focus, conviction and discipline to acieve a goal with determination. Shraddha is derived from two Sanskrit roots:*shrat*meaning "truth," "heart" or "faithfulness," and*dha*, meaning "to direct one’s mind toward." Swami Chinmayananda used to quote this statement of St. Augustine: “Faith is to see believe what we don’t see and its reward is see what we believed!” This message quite subtle because if we don’t see what we believe, it only confirms that we don’t have the Shraddha!!  

When we read the scriptures that include the Vedas, epics, puranas, Bhagavad Gita, etc., we need read with Shraddha. When we read them with Shraddha, we wouldn’t see any contradictions, because contradictions come only with the lack of Shraddha. If we believe that the scriptures only contains the Truth, then if find contradictions, that only confirms our lack of faith!  

With my warm regards,
