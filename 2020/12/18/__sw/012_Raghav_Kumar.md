Namaste Kaul ji

  

Thank you for the clarifications.  

One question arises regarding sAyana vaada. Currently Ashwini, Bharani and one paada of krittika are \*defined for good\* in a 'sidereal' way, as mesha rAShI.(i.e., 'nirayana-vAda' )

  

But, if we define the sankramana points in a sAyana manner as you suggested with various textual references, that would imply that at some point in the past, meSha rAShI would (according to the sAyana calibration) have comprised a different combination of naxatra paadas.

  

Correlations with naxatras:

Is there any textual reference (independent of inferring by sankramaNa definitions) indicating meSha rAShI being defined with a different set of paadas like, say, four paadas of revati and four paadas of Ashwini and one paaada of bharaNi as it would be been defined (if sAyanavAda were to have been in vogue) in about 1100 CE? (assuming earth's axial precession ayanAmsa of about 50 seconds of arc per year).

  

Because your argument would be comprehensively clinched if any pre-Lahiri text defined rAShis in a sAyana manner were referenced. For example, anyone's birth is mentioned as "revatI naxatre meSha rAshau jAtah" instead of mIna rAShau jAtaH etc.

  

If I missed seeing this floating point naxatra definition for the rAShIs in the texts references mentioned by you in your previous posts, kindly point out.
