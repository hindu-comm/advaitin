Namaste Subbu ji, Satyan ji,

  

Subbuji:

  

"I think it leads to the confirmation of the Vedantic doctrine of 'ajnAtasattA of objects is not admissible'. No object can be said to exist unless it is perceived by someone or the other at some time or the other."  

  

This is an interesting corollary. I hadn't intended for this to be extended for jnAtaikasattA.

  

1\) The vyApti dRshyatvAt mithyAtvam only implies that if something is not mithyA it cannot be dRshya.

  

2\) Whereas, jnAtaikasattA means that if something is not known, it does not exist. Here, existence is prAtibhAsika sattA, ie mithyA, and knowability is dRshyatva. Thus, restating the concomitance - if it is not dRshya (not known), it is not mithyA (doesn't exist). Which is a concomitance in the opposite direction to 1.

  

Satyan ji,

The question is - is the object being illuminated by consciousness or is it the attributes (shabda, sparsha rUpa rasa gandha) of the object that are being illuminated?

  

1\) If the former, how is consciousness illuminating the object when it is not in contact with the object?

a\) If it is said that the contact with the object is indirect via the ray of light, the object itself may not exist then, where like in our star example, the star may not exist when its light hits the eye.

b\) If we postulate a direct contact of consciousness with the object, as here the pramAtR chaitanya is the illuminator, we will have to postulate a direct contact with the object through a vRtti. However, then we have to postulate that the vRtti reaches the object, so we are back to square one. In the traditional model, it is not the pramAtR chaitanya that is the illuminator, it is the viShaya adhiShThAna chaitanya (the consciousnesses which is the object's substratum) that is the illuminator in a perception.

2\) If the latter, then the object is not being illuminated, only its attributes are. The object exists independent of the attributes of sound, colour etc, so how is consciousness all illuminating when the object is left unilluminated?

  

I don't have a problem with the mithyAtva of said object, which is still possible in this prakriyA because of dRshyatva hetu. It is the sarvaprakAshakatva that I am not convinced about.

  

Regards,

Venkatraghavan
