The sequence stated above is not correct. You first asked how shivatvam is not an attribute. To which I replied, that is so because it is not a visheShaNa, it is an upalakshaNa of the self. That is, it does not belong to the self, however it is useful in identifying the self.

  

The Atma does not have to drop shivatvam - it was never part of the Atma for it to be dropped. The one seeking the Atma ***uses*** the qualifier shivatva / advaitatva to drop all bheda / dvaita in order to isolate and identify the Atma.The denial of dvaita / bheda leads one to negate that shivatva / advaitatva also (the denial of dvaita / bheda encompasses within it the denial of the svagata bheda / dvaita between the qualifier and qualified too), and what remains is shuddham, which is satyam. This unnameable One which remains, is attributeless.
