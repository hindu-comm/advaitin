Namaste Dennis Ji,

In BSB 1-1-1, Sri Bhagavatpada states

//
ब्रह्मणोजिज्ञासाब्रह्मजिज्ञासा।ब्रह्मचवक्ष्यमाणलक्षणम्‘जन्माद्यस्ययतः’इति। //

// brahmaNo jij~nAsA brahmajij~nAsA \| brahma cha vakShyamANalakShaNam ‘janmAdyasya yataH’ iti \| //

And follows it up with

//
ब्रह्मणइतिकर्मणिषष्ठी,नशेषे;जिज्ञास्यापेक्षत्वाज्जिज्ञासायाः,जिज्ञास्यान्तरानिर्देशाच्च।
//

// brahmaNa iti karmaNi ShaShThI, na sheShe ; jij~nAsyApekShatvAjjij~nAsAyAH, jij~nAsyAntarAnirdeshAchcha \| //

Thus it is in the context of ब्रह्मजिज्ञासा (brahmajij~nAsA ) in the sutra BS 1-1-1

// अथातो ब्रह्मजिज्ञासा ॥ १ ॥ //

// athAto brahmajij~nAsA \|\| 1 \|\| //

that ShaShThI is mentioned, and not in respect of BrahmajnAna and AtmajnAna.
