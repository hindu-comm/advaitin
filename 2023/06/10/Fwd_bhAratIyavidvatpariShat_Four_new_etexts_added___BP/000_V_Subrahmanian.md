Dear list members,

The following 4 etexts from the Ragunatha temple Jammu have been added to the Muktabodha digital library.

The direct link to the Muktabodha digital library is: [https://muktalib7.com/DL_CATALOG_ROOT/digital_library_secure_entry.htm](https://muktalib7.com/DL_CATALOG_ROOT/digital_library_secure_entry.htm)  

``` The etexts are: ```

``` dakṣiṇāmūrtisaṁhitā manuscript 1633k ānandeśvarapaddhatiḥ manuscript 5520 gh bagalāmukhīpañcāṅgam manuscript 6025 ajñānadhvāntadīpikā by somanātha manuscript 4966 ```

``` The transcriptions of these manuscripts have not been normalized.  Word breaks (or lack of word breaks) is as in the devanagari manuscripts.  The letter "v" has been left as "v" whether it represents a "v" or a "b". ```

``` Note: If you only want to browse the manuscripts, the search screen can be hidden by 
clicking the "hide/view search panel" button in the upper right corner of the screen. ```

``` These etexts were created by the Muktabodha Varanasi office from  manuscript images made 
available to the public by the generosity of the eGangotri organisation. ```

``` The etexts were produced under the supervision of Dr. Anirban Dash.  
The transcribers were Mr. Vinay Mishra, Mr. Dharmendra Kumar, and Mr. Sandeep Yadav. ```
