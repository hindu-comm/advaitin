Namaste Viswanath ji,

  



avidyA has to be accepted as beginningless otherwise nitya mokSha will not be possible! And shAstra will also become useless!!

  

How so? If avidyA had a beginning as time t, then before t, there will have to be vidyA/jnAna. That is the state of mokSha. Then, if there was mokSha before t and there was bandha caused by avidyA after t, some reason should be given for this avidyA to have such beginning. Such reason doesn't exist. Then, avidyA will have to be accepted to have come about t without any reason, which means that after all this struggle across countless janmas, if one gets mokSha, there is no guarantee that avidyA will not begin again and cause bandha, which makes mokSha anitya, which is useless for anyone. And the shAstra that guides on getting such anitya mokSha would be futile too.

  

shAstra is never futile; therefore, mokSha has to be nitya through vidyA which counters avidyA. And since there couldn't have been mokSha before avidyA, therefore, avidyA has to have been for ever, anADi, beginningless.

  
gurupAdukAbhyAm,  
--Praveen R. Bhat
