Hare Krishna



I have a query about Susupti.





Is Susupti Avidya or is it Atma Swarupa?



Ø If this query is being asked with the belief that waking state is more real and asking this question from waking state then it is just nidra / tamasa. And like waking and dream it is too avidyA avasthaa.
But when the same state is being analyzed without any prejudices and partiality to waking state then sushupti is avidyA rahita paramAtma sthAna where veda itself not veda. This state experience (sushuptyAnubhava) itself is enough to realize that we are ekaM and adviteeyaM but going to sushupti and experiencing it without jnana is of no use.



In Susupti are all components of Antahkarana in laya?



Ø Since sushupti is antaHkaraNa upashAnta sthiti there is no adhyAsa but there is jnana abhAva ( tattvAgrahaNa) this has been said accepting that in other two states both kAraNa avidyA ( tattvAgrahaNa) and karyAvidyA (anyathAgrahaNa) are there.



Hari Hari Hari Bol!!!

Bhaskar
