Rudra has both Ghora rUpa and AghOra rUpa. Both are there in creation and therefore have to be forms of Rudra. Swami Paramarthananda would put it as: both the benign and the terrible are in creation. We naturally lean toward the benign but as we mature, we start appreciating the terrible too as the same Rudra/Brahman. That's why in the 11th Chapter Vishwarupa darshana we have the terrible aspecttoo shown which Arjuna abhorred and asked Krishna to withdraw.
