It is not my invention Bhaskar ji. It is well-established in siddhAnta. The agrahaNa in sushupti is bheda-agrahaNa or dvitIya-agrahaNa. It is not tattva-agrahaNa //.

This topic seems to be figuring in more than one thread running simultaneously currently. I had some difficulty in deciding where to post my response . But finally landed on the above quote from one of the latest posts from Sudhanshu Ji. The first para in above quote is by Bhaskar Ji while the second para is response by Sudhanshu Ji.

I thought the following citation from MandUkya Bhashya on mantra 5 would settle the issue hopefully. Atleast from factual point of view. Sri Bhagavatpada admits both the understandings (bheda-agrahaNa or dvitIya-agrahaNa as well as tattva-agrahaNa ) for agrahaNa as far as sushupti is concerned. I have not given the English translation of the kannada version by Sri SSS. However I confirm that it also endorses the above view ( though there could be some differences on some other
issues).

// दर्शनादर्शनवृत्त्योःस्वापस्य तुल्यत्वात्सुषुप्तग्रहणार्थं यत्र सुप्त इत्यादिविशेषणम्। अथवा, त्रिष्वपि स्थानेषु तत्त्वाप्रतिबोधलक्षणः स्वापोऽविशिष्ट इति पूर्वाभ्यां सुषुप्तं विभजते //

// darshanAdarshanavRRittyoH svApasya tulyatvAtsuShuptagrahaNArthaM yatra supta ityAdivisheShaNam \| athavA, triShvapi sthAneShu tattvApratibodhalakShaNaH svApo.avishiShTa iti pUrvAbhyAM suShuptaM vibhajate //

Translation ( Swami Gambhirananda ) // Since Sleep, consisting in the unawareness of Reality, is a common feature of the two states ( of waking and dream ) where there are the presence and absence ( respectively ) of perceptible gross objects, therefore the adverbial clause, \*\* Where the sleeper \*\* etc ( Note 1 ) is used in order to keep in view the state of deep sleep. Or since sleep, consisting in the unawareness of Reality, is equally present in all the three states, deep sleep is being distinguished ( by that clause ) from the earlier two states ( Note 2).

Note 1 ;; That is to say, the portion \*\* does not desire any enjoyable thing \*\* etc occurring in the clause \*\* Where the sleeper \*\* etc; or the portion \*\* does not \*\* etc distinguishes deep sleep from other two states which have the common feature of unawareness.

Note 2 ;; Since by the use of the portion \*\* does not see any dream \*\* that is to say \*\* does not have any false perception of Reality \*\*, the other two states of dream and waking can be eliminated the addition of the portion \*\* does not desire any enjoyable thing \*\* may seem to be redundant if we follow the first interpretation. To obviate this difficulty the second explanation is introduced. Non-perception being a common factor of the three states, sleep can be distinguished by the absence of desire //.

Translation and Commentary by Sri SSS // ನೋಡುವದು, ನೋಡದೆ ಇರುವದು ಎಂಬ ವೃತ್ತಿಗಳೆರಡರಲ್ಲಿಯೂ ( Note 1 ) ತತ್ತ್ವ ವನ್ನು ತಿಳಿಯದೆ ಇರುವದೆಂಬ ನಿದ್ರೆಯು ( Note 2 ) ಸಮಾನವಾಗಿರುವದರಿಂದ ಸುಷುಪ್ತವನ್ನೇ ತೆಗೆದುಕೊಳ್ಳಬೇಕೆಂದು (ತಿಳಿಸುವದಕ್ಕೆ) “ಯತ್ರ ಸುಪ್ತ'' (ಎಲ್ಲಿ ನಿದ್ರಿಸುವವನು) ಎಂದು ಮುಂತಾದ ವಿಶೇಷಣ(ವನ್ನು) ಕೊಟ್ಟಿರುತ್ತದೆ. ಅಥವಾ ಮೂರು ಸ್ಥಾನ ಗಳಲ್ಲಿಯೂ ತತ್ತ್ವವನ್ನು ತಿಳಿಯದಿರುವದೆಂಬ ನಿದ್ರೆಯು ( Note 3 ) ಸಮಾನವಾಗಿದೆಯಾದ್ದ ರಿಂದ ಮೊದಲನೆಯ ಎರಡು (ಸ್ಥಾನಗಳಿಂದ) ಸುಷುಪ್ತವನ್ನು ವಿಂಗಡಿಸಿ (ಶ್ರುತಿಯು) ಹೇಳುತ್ತಿದೆ :-

ಎಲ್ಲಿ ಎಂದರೆ ಯಾವ ಸ್ಥಾನದಲ್ಲಿ ಅಥವಾ (ಯಾವ) ಕಾಲದಲ್ಲಿ ನಿದ್ರೆ ಮಾಡುತ್ತಿರುವವನು ಯಾವ ಕಾಮವನ್ನೂ ಬಯಸುವದಿಲ್ಲವೋ ಯಾವ ಕನಸನ್ನೂ ಕಾಣುವದಿಲ್ಲವೋ (ಅದು ಸುಷುಪ್ತವು ಎಂದರ್ಥ). ಏಕೆಂದರೆ ಸುಷುಪ್ತದಲ್ಲಿ ಮೊದಲನೆಯ ಎರಡು (ಅವಸ್ಥೆಗಳಲ್ಲಿರುವಂತೆ) ತಪ್ಪಾಗಿ ತಿಳಿಯುವದೆಂಬ ಕನಸು ಕಾಣುವದಾಗಲಿ ಬಯಕೆಯಾಗಲಿ ಯಾವದೂ ಇರುವದಿಲ್ಲ.

Note 1 ;; ದರ್ಶನವೃತ್ತಿ ಎಂದರೆ ಸ್ವಪ್ನವು ; ಅದರ್ಶನವೃತ್ತಿ ಎಂದರೆ ತನಿನಿದ್ರೆ. ದರ್ಶನವೃತ್ತಿ ಎಂದರೆ ಎಚ್ಚರವೆಂಬ ವ್ಯಾಖ್ಯಾನವು ಸರಿಯಲ್ಲ. ಬೃ. ಭಾ, ೪-೩-೧೭, ಛಾಂ. ಭಾ. ೬-೪-೧ ನೋಡಿ. ವೃತ್ತಿ ಎಂದರೆ ಸ್ಥಾನವು , ಅವಸ್ಥೆ ; ೨-೯ ನ್ನು ನೋಡಿ. ಕನಸಿನಲ್ಲಿಯೂ, ತನಿನಿದ್ರೆ ಯಲ್ಲಿಯೂ ಎಚ್ಚರದ ವಸ್ತುಗಳ ಅರಿವಿಲ್ಲ ; ಆದರೆ ಕನಸಿನಲ್ಲಿ ಹುಸಿತೋರಿಕೆಗಳ ದರ್ಶನವಿದೆ.

Note 2 ;; ತತ್ವಾಪ್ರತಿಬೋಧವೆಂದರೆ ವ್ಯಾವಹಾರಿಕವಸ್ತುತತ್ತ್ವವನ್ನರಿಯದಿರುವದು ಎಂದು ಭಾವ.

Note 3 ;; ಇಲ್ಲಿ ತತ್ವಾಪ್ರತಿಬೋಧವೆಂದರೆ ಪರಮಾರ್ಥವಾದ ಆತ್ಮತತ್ತ್ವವನ್ನು ತಿಳಿಯದಿರುವದು ; ಇದು ಮೂರು ಅವಸ್ಥೆಗಳಿಗೂ ಸಮಾನವಾದ ನಿದ್ರೆ // .
