This Mahapralaya, also called Brahmapralayaoccurs at the end of a Kalpa..



praNAms

Hare Krishna



And at the end of this mahApraLaya everything goes back to its beeja rUpa i.e. avyAkruta rUpa for which bhagavata is sAkshiNi…mahA pralaya sAkshiNi. If that is not the case and if each and every kalpa there is some new set of jeeva-s born then there is dOsha of kruta praNAsha and akruta abhyAgama…bhAshyakAra discusses this dOsha if new set of jeeva-s born without any reason and some set of jeeva-s dissolved on its own without doing anything!!! dhAta yathA pUrvamakalpayatu is the shruti vAkya.



Hari Hari Hari Bol!!!
