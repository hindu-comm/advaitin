Namaskaram Kalyan ji,

  

\<\< Opponent is claiming that - Mithya snake can be superimposed on a Satya Rope only if there is an experience of a Satya snake beforehand. \>\>  
  

This claim is invalid. Mithya snake can be superimposed even if there is an experience of a mithya snake beforehand. The prior snake doesn't have to be satya. This avoids all logical fallaciesas karma-janma are anadi and the mithya snake is a perceived ontological entity created by Ishvara's maya.

  

prostrations,

Vikram
