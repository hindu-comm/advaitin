There is an analogy being made. Think about thequestion being asked. If a tree falls in the forest, but there is no one there to hear it, does it make a sound? In ordinary common sense, what is this asking? Is it asking about sound waves?Or about something else? It is asking about experience, is it not? Doesexperience exist without an experiencer?

  

Similarly, what does it mean to say that the world is an illusion? It means to ask the question: does the world exist if there is no one there to experience it? Can that question exist if there is no one there to ask it?

  

We need to resist the urge to put a simple answer to these questions and note what they are pointing at.

  

Akilesh Ayyar
