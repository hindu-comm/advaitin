Namaste Bhaskar ji.

  

It is a very substantial question. Please apply mind.

  

Is it mrit-piNDa-vishesha or mrit-piNDa-sAmAnya or mrit --- which one can be averred to be the kAraNa of pot.

  

If it is a kAraNa, of course, we agreed above that it has to be pariNAmI-kAraNa. If it is not a kAraNa, it cannot be pariNAmI-kAraNa as well.
